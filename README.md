# SmartTrack

Dijital bir takograf cihazıyla Bluetooth üzerinden eşleşip sürüş verilerini takip eden bir Flutter uygulaması.

## Başlarken

Bağımlılıkları yükleyin:

```bash
flutter pub get
```

Uygulamayı çalıştırın (bağlı bir cihaz/emülatör seçin, veya `-d chrome` / `-d windows`):

```bash
flutter run
```

## Geliştirme komutları

- Statik analiz: `flutter analyze`
- Tüm testleri çalıştır: `flutter test`
- Tek bir test dosyasını çalıştır: `flutter test test/kline_protocol_test.dart`
- Build al: `flutter build apk` / `flutter build ios` / `flutter build web`
